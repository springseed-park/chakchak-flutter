# Google Play 데이터 보안 작성 기준

Play Console 제출 시 실제 출시 버전과 대조해 최종 응답한다. 아래 내용은 현재 설계 기준 초안이다.

| 데이터 유형 | 수집/공유 | 목적 | 삭제 지원 |
|---|---|---|---|
| 이름, 이메일, 프로필 사진 | 수집 | 계정 관리, 개인화 | 회원 탈퇴 |
| 사용자 ID | 수집 | 인증, 사용자 데이터 분리 | 회원 탈퇴 |
| 사진 | 수집 | 옷장 등록, 코디 추천 | 앱 내 삭제/회원 탈퇴 |
| 대략적·정확한 위치 | 기능 사용 시 수집 | 현재 위치 날씨 | 앱 종료 후 지속 추적하지 않음 |
| 일정 제목·시간 | 선택 시 수집 | 일정 기반 코디 추천 | 앱 내 삭제/연결 해제 |
| 키·몸무게·얼굴 톤·선호 스타일 | 선택 시 수집 | 개인화 추천 | 수정/회원 탈퇴 |
| AI 대화 내용 | 수집 | 메이트 답변 생성 | 대화 초기화/회원 탈퇴 정책 적용 |
| 앱 상호작용·오류 정보 | 출시 설정에 따라 수집 | 안정성·오류 분석 | 보관 기간 후 삭제 |

## 공유·처리 제공자

- Google Firebase: 인증, 저장, Functions
- Google Calendar: 이용자가 연결한 경우 일정 읽기
- Groq: AI 응답 생성에 필요한 질문과 최소 코디 문맥
- 기상청 API 허브: 좌표를 변환한 격자 기반 예보 조회

## Play 심사 전 확인

- 모든 전송은 HTTPS를 사용한다.
- 앱 내에서 계정 삭제를 요청할 수 있다.
- Play Console의 계정 삭제 웹 URL 요구가 적용되면 별도 삭제 안내 페이지를 제공한다.
- 위치 권한은 기능 실행 직전에 요청하고 거부 시 지역 직접 선택을 제공한다.
- 사진 권한은 Android Photo Picker 우선으로 구성한다.
- 실제로 넣지 않은 Analytics/Crashlytics/광고 SDK를 데이터 보안 양식에 미리 선언하지 않는다.
